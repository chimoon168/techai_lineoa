## 2. LINE 使用者端（lineoa）

### 2.1 LIFF 頁（帳號綁定、業務功能）

| Token | 色碼 | 用途 |
| --- | --- | --- |
| `--line` | `#06C755` | LINE 綠：主按鈕、頂列、進度 |
| `--line-dark` | `#05A648` | hover、進行中步驟 |
| `--text` | `#1E1E1E` | 內文 |
| `--text-sub` | `#8E8E93` | 說明 |
| `--border` | `#E5E7EB` | 框線 |
| `--bg` | `#F2F4F6` | 頁面背景 |
| `--red` | `#FA5151` | 錯誤 |
| `--orange` | `#E8912D` | 等待中、警示 |

規則：

- 手機寬度優先（360–420px），單欄表單，主按鈕全寬 LINE 綠。
- 頂部顯示 OA 名稱「PXEC 小露助理」與流程進度（綁定：開啟頁面／輸入員編／B2E查核／Email驗證／完成）。
- 結果頁：圓形圖示（成功綠、警示橘、錯誤紅、資訊藍）＋標題＋說明＋錯誤代碼與 correlation ID（小字灰底）。
- Email 一律遮罩（`ch***o@pxmart.com.tw`）；不顯示完整 Token。
- 商品編號用畫面數字鍵盤，不叫出手機鍵盤（見 10）。
- 錯誤訊息不揭露員工主檔細節。

### 2.2 圖文選單圖片

| 版型 | 尺寸 | 用途 |
| --- | --- | --- |
| 半版 2 格 | 2500 × 843 | UNBOUND、10 基本使用者（BOUND_GENERAL） |
| 全版 4 格 | 2500 × 1686 | 50 廠服 |
| 全版 6 格 | 2500 × 1686 | 20 全聯採購 |

- PNG／JPEG、≤ 1 MB；區塊順序左上 → 右下。
- 選單列文字 ≤ 14 字。
- 檔名：`richmenu_{身份代碼或 UNBOUND}_{名稱}_{版型}.png`。

### 2.3 操作示意頁（06_LINE功能操作）

說明型頁面採中性藍灰（`--accent #0A6BC4`、`--fg #18222C`、`--muted #5D6A77`），字體 Noto Sans TC＋IBM Plex Mono（API 區），支援深色模式；手機模擬區固定淺色、LINE 綠 `#06C755`。

## 3. B2E 後台（lineoa_b2e）

沿用 B2E 既有後台樣式（`b2e.css`）：側欄 `#2C3E50`、背景 `#EEF0F3`、主色 `#0D6EFD`、成功 `#198754`、危險 `#DC3545`。

身份顏色（與 B2E 人員角色頁一致）：

| 狀態 | 顯示 |
| --- | --- |
| 未設定（null） | 灰色「未設定」＝無小露資格 |
| 10 基本使用者 | 藍色 |
| 其他身份 | 綠色 |

## 4. 共通寫作規則

- 系統名稱：後台「小露AI」、LINE OA「PXEC 小露助理」；不再使用「語音小露」「全聯智能服務」。
- 身份寫法：`代碼 名稱`，如「20 全聯採購」；選單類型用英文代碼 UNBOUND／BOUND_GENERAL／IDENTITY。
- 日期 `YYYY-MM-DD`，時間 `YYYY-MM-DD HH:mm`（24 小時制）。
- 原型專用控制區（情境切換、模擬結果）以虛線框標示「正式版不顯示」。
- 畫面文字用台灣慣用語、全形標點。
