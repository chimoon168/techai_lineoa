## 已知與 11/16 實作不一致處（摘要）

- 綁定流程：舊規格為「員編 → 導向 B2E OIDC → Email 驗證」；11/16 實作主流程為「LIFF ID Token → 員編 → B2E 即時查核 → 公司 Email 一次性驗證」，**不跳轉 B2E OIDC 網站**。
- 技術棧：舊規格寫 .NET 8＋Google STT＋Google Docs；實作為 ASP.NET Core 10＋Gemini（逐字稿與摘要）＋AWS SES／S3。
- 後台登入：畫面規格書為帳號／密碼／Token 三欄 mock；實作為 B2E OIDC SSO，限 Identity=90（小露SYSOP）。
- 圖文選單綁定身份：畫面規格書為寫死 5 選項；實作改為 UNBOUND／BOUND_GENERAL／IDENTITY 三類，IDENTITY 對應 B2E LINE OA 身份。

詳細對照見 `sa/00_小露AI_開發規格書_總覽.md` §6。
