對照後端處理邏輯（依《LINE LIFF 綁定詳細流程圖》）

① 開啟頁面：LIFF 取得 LINE User ID，查詢 public.sys_line_bindings 是否已存在對應綁定紀錄。
② 員編驗證：查詢 SQL Server USR_Member（EmployeeNumber = 輸入值 且 Status = 1）。
③ OIDC 身份驗證：LuluOfficeBot 後端發起 B2E OIDC Challenge，經企業 SSO 驗證後由 OIDC 回傳員工 Email。
④ 身份比對：比對 OIDC 回傳 Email 是否與 USR_Member.Username 一致，一致才寄出驗證信。
⑤ Email 驗證：員工點擊信中連結，系統確認驗證 Token 有效且未過期。
⑥ 完成綁定：正式寫入 sys_line_bindings，LINE 官方帳號推播「綁定完成」訊息。
此頁面為前端互動原型，所有帳號、員編、Email 皆為模擬資料，僅供流程展示與內部討論使用｜PXEC 技術處辦公室自動化
